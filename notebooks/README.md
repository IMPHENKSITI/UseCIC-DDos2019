# Folder Jupyter Notebooks

Gunakan folder ini untuk eksperimen dan eksplorasi data:
- `eda.ipynb`: Exploratory Data Analysis, visualisasi distribusi kelas serangan DDoS, korelasi fitur, dan deteksi anomali.
- `model_training.ipynb`: Eksperimen perbandingan algoritma ML (misal Random Forest vs XGBoost vs SVM vs KNN), tuning hyperparameter, dan evaluasi metrik (Confusion Matrix, Precision, Recall, F1-Score).
