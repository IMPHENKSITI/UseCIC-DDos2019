# Folder Dataset

Letakkan dataset deteksi DDoS di folder ini:
- `dataset/raw/`: Tempat menyimpan file dataset asli (misal file CSV dari CIC-DDoS2019, UNSW-NB15, atau file `.pcap`).
- `dataset/processed/`: Dataset yang sudah dibersihkan, dinormalisasi, atau hasil feature selection yang siap untuk training.
- `dataset/sample/`: Cuplikan sampel kecil dari dataset (misal 1000 - 5000 baris) untuk pengujian cepat tanpa membebani memori.
