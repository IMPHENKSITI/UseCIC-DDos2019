# Folder Model Machine Learning

Letakkan artefak model hasil training di folder ini:
- `best_model.pkl`: Model machine learning yang sudah dilatih (misalnya Random Forest atau XGBoost).
- `scaler.pkl`: StandardScaler / MinMaxScaler untuk normalisasi fitur.
- `label_encoder.pkl` (opsional): Encoder nama kelas/label.
- `features.json` (opsional): Daftar nama fitur yang digunakan saat pelatihan agar urutan input selalu konsisten.
